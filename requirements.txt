# TagScribeR shared dependencies (all platforms / GPU backends).
#
# torch / torchvision are deliberately NOT listed: tools/install.py installs the
# correct build first (ROCm multi-arch, CUDA 12.8, or CPU). Listing torch here
# would let pip replace a ROCm install with a CUDA wheel.
#
# The torch / ROCm stack matches the Fizgig trainer exactly (see tools/install.py).
# Transformers deliberately differs: Fizgig pins 4.57.x for its Qwen3-VL text
# encoder, but every 2026 VLM family (Qwen3.5/3.6/3.8 = qwen3_5, Gemma 4 = gemma4)
# requires Transformers 5.x. Qwen3-VL remains fully supported in 5.x.
